# 日本語コピー規約 (Copy Style Guide)

## Summary

ぬるぬるの UI コピーは、海外 Nostr クライアントの和訳でも、Twitter / X のミラーでもない。日本語日常語として読めるか・聞こえるかを基準にする。本ページは判断時の参照規約。

## 基本原則

1. **直訳しない。** 英語 UI の原語に引きずられない。"Post" は「投稿」ではなく文脈次第で「書く」「送る」「のせる」。
2. **音読して不自然なら採用しない。** 黙読チェックではなく音読チェック。
3. **長さより節度。** 短くするための無理な省略 (体言止め多用) は避ける。
4. **既存採用コピーを尊重する。** 後述の既存ペアを別表現に置換しない。
5. **専門用語を表に出さない。** [[not-doing]] と整合。

## 既存採用コピー (置換禁止)

| 用途 | 採用コピー | 補足 |
|---|---|---|
| 折りたたみ展開 | もっと見る / 閉じる | 「続きを読む」「全文表示」等に変えない |
| 投稿アクション | (アイコンのみ) | reply ボタンは設置しない ([[../decisions/adr-0005-postactions-no-reply-button|ADR-0005]]) |
| メインタブ (iOS zero-base target) | ホーム / トーク / タイムライン / ミニアプリ | ADR-0022。root に ろくなな / ニュース を置かない |
| いいねアイコン | thumbs-up | heart に変えない (既存規約) |

## トーン

- **やわらかい敬体**を基本。「〜してください」より「〜してね」「〜しよう」を選べる場面では選ぶ (ただし鍵・セキュリティ画面では敬体を保つ)。
- **絵文字は装飾ではなく意味**を持たせる。並べ装飾しない。
- **記号は和文に合わせる。** 三点リーダーは「…」、波ダッシュは「〜」、感嘆/疑問符のあとは全角空白。

## 場面別ガイド

### 空状態 (Empty state)

- ❌ "No posts yet."「投稿がありません。」
- ✅「まだしずかだね。」「ここに新しい投稿が並ぶよ。」

### エラー

- ❌「エラーが発生しました。コード: 0x80004005」
- ✅「うまく送れなかった。電波かリレーの調子かも。もう一度ためしてみる?」

技術的詳細はオプショナルに見せる ([詳細] を畳む)。

### 確認ダイアログ

- 動作の重さに合わせる。鍵削除のような不可逆操作には敬体 + 明示的な確認語。
- 「本当に削除しますか?」より「ここで削除すると、もとに戻せないよ。」のように**結果を語る**。

### 鍵・セキュリティ画面

- 敬体固定。
- 「秘密鍵」「公開鍵」のような語は必要なら見せるが、説明文を必ず添える。
- 恐怖は煽らない。事実だけ伝える。

## レビューフロー

1. PR にコピー変更が含まれる場合、起案者は本ページへのリンクを PR 説明に貼る。
2. Design Crit で1議題として扱う (短時間で良い)。
3. 大規模なコピー刷新は ADR を残す。
